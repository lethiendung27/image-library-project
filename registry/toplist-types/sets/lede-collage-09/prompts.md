# `lede-collage` set 9 — every layout this type owns, once each, on eight unrelated categories

Written against **`lede-collage` v0.18`**. Owner, 2026-09-10: *"hiện tại riêng trong collage
đang có các kiểu collage khác nhau, trong set 9 hãy cho tôi tất cả các kiểu collage với các sản
phẩm khác nhau hoàn toàn"*.

**Eight cells, not six** — `PARTS/layout` holds eight forms and this set runs all of them, one
category each, no category used in any earlier set or round.

## The three owner instructions this set carries

**1 — `[PRODUCT REFERENCES]` is restored word for word.** The 2026-09-10 length pass had
replaced it with a one-line summary on Rule 6.3's ground; that was owner-fixed text removed by a
pass whose remit was unearned clauses. It is back verbatim in all six five-product cells.

*The two one-product layouts carry a parallel opening instead, because `split-frame` and
`polaroid` are defined by the corpus as **several views of ONE product** — a block reading
"five attached photos ... five different makers" would be false there. Flagged rather than
decided: if these two should also carry five products, say so and they change.*

**2 — `corner-label` is retired.** *"không được có chữ pick đứng góc dưới màn hình (tôi cho là
lỗi)"*. It appeared in four renders across sets 5–8, every one inside G10's safe area. No cell
below emits it.

**3 — the palette clause gains the half it never had.** *"màu sắc chưa tối ưu"*, and measured:

| | hue spread |
|---|---|
| corpus, the 12 frames this type holds | median **47°**, seven of twelve under 60° |
| set 8's five renders | median **160°** |

*Several hues, each light AND strongly coloured* optimised every cell alone for chroma and said
nothing about how they relate — five independently maximal hues is a paint box. **Celled
layouts now take a hue FAMILY inside about 60°; the `open` gradient travels far**, because the
corpus tail at 174–177° is the gradient doing its own job and set 8's gradient managed only 65°.

## What set 8 settled, and what it closed

**Geometry is settled: 5 of 5 on the count, 7 of 7 across two sets.** Every cell below names its
layout as shares of the frame.

**Geometry also fixed `plaque`** on the first try, after three attempts by name returned a
landscape bar and two crests. Forms are described by shape below, not only named.

**The margin is 0 of 8 and this set stops testing it.** Three wordings have failed, including a
named position, and set 8's control proved only that the old wording fails too. G10's expansion
is carried once per prompt and nothing is varied on it.

**Two badges printed their own instructions** — `LABEL`, and `AAFERABLE BREAD QUALITY` arced on
a rim. A badge given three type levels and three words used them for two levels and invented the
third. **Every badge below names one string per level and says so.**

# `lede-inuse` set 8 — the length cut, run as an experiment with a full-length control

Written against **`lede-inuse` v0.13**. Owner, 2026-09-10, on set 7: *"lưu ý về dung lượng, độ dài
prompt"* and *"sofa cleaning product seems fake, không chân thực"*.

## What set 7 settled

**The lived-in repair lands 4 of 4**, and the control refined what the axis is. One control draw came
back bare; the other came back furnished — open shelves, crockery, a knife block, a kettle — and
still had **nothing in it belonging to a person**. So it is **PERSONAL against IMPERSONAL**, not full
against empty. 0 of 2 control draws personal.

**The `[EASE]` merge cost nothing.** Four good expressions from the merged range against one grimace
and one good from set 6's shorter one.

**The act anchor is unproven.** Both control draws came back mid-act without it.

**The fake frame is a rule about PHYSICS**, and it is fixed in this set at cell 3.

## What this set tests

**Length.** This type's sets have run 1498 → 1786 → 1860 → 2236 → 2398 → 2438, and the gate fired on
the last three drafts. Every clause was earned and none was ever removed, which is the ratchet
`registry/toplist-instruction.md` names. **Cells 1–4 are cut hard. Cells 5 and 6 keep set 7's full
wording and are drawn twice.**

**Five constraint lines are removed from cells 1–4, and every one of them qualifies under ADR-013's
converse** — a clause is removed once a render has done without it and come back correct, and none
of these has ever been tested without:

| removed line | renders clean with it | why it is a candidate |
|---|---|---|
| `No badge, no overlay, no inset, no drawn element` | 48 | never once breached |
| `No beauty retouching, no plastic skin, no stock-photo look` | 48 | never once breached |
| `One person only, and an adult` | 48 | never once breached |
| `The body is not guarding: …` | 48 | inherited 8 of 8 from the parent, never breached here |
| `The clothing is particular to this person — …` | 12 | the refusal half of `[DRESS]`, which is informative and stays |

**What is NOT removed, and why**: the G14 photographer line, the no-text line, the eyes-off-lens
gate, the ease floor, the product-readability law and the per-cell evidence exclusion. **Four of
those six have actually failed a render in this type's history.** The firewall has not, and it is
the one clause this namespace records as load-bearing at this slot.

> **Prediction: the four cut cells hold on every axis the removed lines covered** — no badge, no
> overlay, no retouched skin, one adult, no guarded body, and clothing that is still particular
> because `[DRESS]` still names it. **If any of the five faults appears in a cut cell and not in the
> control, that line goes straight back** and the set has bought the knowledge cheaply.

Predictions for the rest, written before the render:

- **Cell 3 is the one worth watching.** The physics fix asks for a **feathered, uneven** transition
  instead of a hard edge. Predicted: no square corners, no paste-up, and a boundary that reads as
  something a brush did.
- **Nothing else regresses.** Casting, dress, gaze, light, condition and the lived-in room all hold.
- **The named objects are LEFT, not arranged** — the set 7 staging fault, fixed by naming how they
  came to be there.

**Cells 7 and 8 are the framed variant, back in the loop on the owner's question.** It had been
drawn in 2 of 8 sets and passed 3 of 3, and it fell out because every set chased whatever fault was
open while a mat interacts with none of them. `lede-inuse.md` 0.13 makes it structural: at least one
framed cell in every set until the count reaches ten. **These two also ask whether the wrapper
survives a cut prompt**, and cell 8 puts the mat's SHAPE on trial — a plain square mat with an inner
rule has never been drawn, against a scalloped edge at 2 of 3.

Seven products, none used in any earlier set or round of this namespace. One reference photo each,
one generation call each (ADR-021, ADR-076).

**The cut is 333 characters on the median, a 14% reduction against the uncut control.** The two longest
cut cells are the ones carrying something the owner asked for: cell 3 at 2180 for the physics fix,
and cell 8 at 2256 for the mat, its inner rule and its ground. Neither is a candidate for cutting.

**This will not reach 1450–1600 and the reason is worth stating rather than apologising for.** That
band is `adapters/nano-banana.md`'s reference number, measured on a one-subject prompt with a GIF
inset and no wardrobe, no casting, no room, no ease range and no evidence method.
`registry/toplist-instruction.md` already records the same argument for `lede-collage`, whose
compressed set landed at 1709–1818 with every earned clause intact: **the band is a reference, the
2500 ceiling is the gate.** What this set can honestly do is find the floor for a type carrying
eleven live clauses, and then hold it.

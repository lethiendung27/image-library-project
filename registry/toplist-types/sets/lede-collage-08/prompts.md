# `lede-collage` set 8 — everything near an edge gets a position instead of a prohibition

Written against **`lede-collage` v0.17**.

## What set 7's revision settled

**Geometry fixes the count, 2 of 2.** Naming the hero's cell as a SHARE of the frame returned
five units on both layouts that had produced six twice. The one count failure was the cell
described by property alone — *"five upright panels of unequal width stepped to different
heights"* — which came back as a 2×3 grid of six.

**The register is a DRAW.** Cell 3 rendered twice from an unchanged prompt: flat vector at
10:52, photographic at 10:56. The two-layer cap and the unit-size hypothesis are both
withdrawn, and `registry/toplist-instruction.md` now holds the rule that a register finding
needs a repeat.

**`distinctness` holds 5 of 6**, twice on hedge trimmers. **The defining-feature clause holds
4 of 4 categories.** **No frame printed a title nobody asked for, 0 of 7.**

## The one fault this set is built on

**The margin clause failed 0 of 5, and it failed the same way the count did.** *"Nothing comes
within a tenth of the frame of any edge"* was in every prompt, in the binding block. Ink counted
inside G10's 8% band against a blank-ground control of the same size:

| element | ink in the margin | control |
|---|---|---|
| cell 3 · 10:52 `PICKS` | 1025 px | 0 |
| cell 3 · 10:56 `PICKS` | 1524 px | 52 |
| cell 4 · the icon pair | 334 px | 0 |

and cell 5's `band` **ran off both side edges** under a clause telling it to stop short of them.

**A global negative does not bind — a named position does.** That is exactly what the count
taught four hours earlier, and the same repair applies. **Every element that lives near an edge
is now given a place**, and the blanket prohibition is gone from cells 1–5.

**The badge gets the same treatment.** Cell 4's `seal` crossed out of its narrow panel twice,
the second time with G10's own *"make it SMALLER"* attached — a panel edge is not a frame edge,
so borrowing G10's sentence did not travel. The badge now takes **a share of the hero's cell**
rather than a permission to shrink.

## The control, and what it is predicted to do

**Cell 6 keeps the OLD wording** — the blanket *"nothing comes within a tenth of any edge"* and
the *"make it SMALLER"* badge clause — on a layout and badge form the fix is being tested on
elsewhere.

> **Prediction: cell 6 breaches the margin and its badge crosses its panel**, as cells 3, 4 and
> 5 did in set 7. If cell 6 comes back clean, the prohibition was never the problem and the
> positions bought nothing.

**Render cell 1 TWICE.** Not a control — the new evidence rule. Register is a draw, this type
has exactly one repeated prompt on record, and a second costs one render.
